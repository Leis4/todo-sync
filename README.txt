ОБЩИЙ СПИСОК ДЕЛ

Для запуска нужен установленный Python 3 и подключение к Интернету
при первой установке библиотек.

1. ЗАПУСК НА ОДНОМ КОМПЬЮТЕРЕ

Откройте папку проекта и дважды нажмите START.bat.
Появятся сервер и два окна приложения. Окно сервера не закрывайте.
Добавьте задачу в одном окне: во втором она появится при обновлении.

2. ЗАПУСК НА ДВУХ КОМПЬЮТЕРАХ В ОДНОЙ СЕТИ

На первом ПК откройте SERVER_ONLY.bat.
Узнайте его IPv4-адрес командой ipconfig.
На втором ПК скопируйте исходные файлы проекта, откройте
CLIENT_OTHER_PC.bat и введите IPv4 первого ПК.
На втором ПК сервер запускать не нужно.

3. ГДЕ ХРАНЯТСЯ ДАННЫЕ

Файл tasks.db создаётся рядом с server.py при первом запуске.
Если переходите со старой версии, перенесите tasks.db в эту папку
при остановленном сервере. Не удаляйте базу с нужными задачами.

4. ОСНОВНЫЕ ФАЙЛЫ

server.py - FastAPI и SQLite.
client.py - графическое окно PySide6.
requirements.txt - зависимости Python.
START.bat - сервер и два клиента на одном ПК.
SERVER_ONLY.bat - только сервер.
CLIENT_OTHER_PC.bat - клиент с адресом сервера.
report/ - пояснительная записка в LaTeX и PDF.

5. ДОКУМЕНТАЦИЯ

Папка report содержит исходные файлы LaTeX, иллюстрации и собранный PDF.
